== Description ==

ProfitBenefit is a modern WordPress theme designed for business tool directories, software review sites, and productivity blogs. Perfect for comparing products, hosting reviews, and SaaS comparisons.

Features:
* Responsive design
* Custom post meta boxes for product comparisons
* Featured content sections
* Category-based content tabs
* Custom widgets for top picks and popular posts
* SEO optimized structure
* Translation ready

== Installation ==

1. Upload the theme folder to /wp-content/themes/
2. Activate the theme through 'Appearance > Themes'
3. Configure theme settings via Customizer
