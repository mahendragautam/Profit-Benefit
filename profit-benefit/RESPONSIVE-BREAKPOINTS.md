# ProfitBenefit Theme — Mobile-only responsive policy

This theme has been converted to a mobile-first, single-surface stylesheet.

- Supported base width: 320px and up (mobile devices).
- All breakpoint-specific rules for larger screens have been removed from
    the CSS to enforce a single mobile experience.

If you later need to reintroduce desktop or tablet layouts, restore the
relevant rules from the repository history or open a dedicated branch/PR
to re-add breakpoint-specific styles.

Last updated: December 27, 2025
