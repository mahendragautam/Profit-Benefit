# Theme spec

This folder holds the theme specifications and documentation.

- **Machine specs:** [machine-spec](machine-spec/) — canonical, topic-focused markdown files used by automation.
- **Human docs:** [docs](docs/) — implementation guides, migration notes, troubleshooting, completion summary, and future improvements.

Quick links:

- Machine specs: `machine-spec/theme-accessibility.md`, `machine-spec/theme-security.md`, `machine-spec/theme-performance.md`, `machine-spec/theme-testing.md`, `machine-spec/theme-woocommerce.md`, etc.
- Docs: `docs/IMPLEMENTATION-GUIDE.md`, `docs/MIGRATION-GUIDE.md`, `docs/TROUBLESHOOTING-GUIDE.md`, `docs/FUTURE-IMPROVEMENTS.md`.

Use the `machine-spec` files as the authoritative source when automating checks or generating guidance; use `docs` for hands-on instructions and longer-form content.
